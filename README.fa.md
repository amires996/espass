# ESPass 🔐
### رمزهای عبور شما؛ روی دستگاه شما؛ تحت کنترل شما

**ESPass** یک نرم‌افزار دسکتاپ مدرن برای مدیریت رمزهای عبور است که با Python، PySide6، SQLite، Argon2id و AES-256-GCM توسعه داده شده است.

این پروژه با تمرکز بر حریم خصوصی، سادگی و امنیت طراحی شده است. اطلاعات ورود شما به‌صورت رمزنگاری‌شده و محلی نگهداری می‌شوند و رابط کاربری مدرن، تجربه‌ای روان و کاربردی فراهم می‌کند.

> [!IMPORTANT]
> ESPass یک پروژه شخصی در مقیاس جامعه توسعه‌دهندگان است و هنوز تحت ممیزی امنیتی مستقل قرار نگرفته است. استفاده از آن بر عهده کاربر است. همیشه یک نسخه پشتیبان رمزنگاری‌شده و جداگانه از گاوصندوق خود نگه دارید.

## ✨ امکانات

- **🔒 گاوصندوق رمزنگاری‌شده:** محافظت از اطلاعات با رمز اصلی که ذخیره نمی‌شود.
- **🛡️ رمزنگاری مدرن:** استفاده از Argon2id برای مشتق‌سازی کلید و AES-256-GCM برای رمزنگاری احراز هویت‌شده.
- **💻 حریم خصوصی محلی:** نگهداری اطلاعات به‌صورت محلی و رمزنگاری‌شده در SQLite.
- **🎨 رابط کاربری مدرن:** پشتیبانی از تم تاریک و روشن.
- **🌍 پشتیبانی از دو زبان:** رابط کاربری انگلیسی و فارسی.
- **🗂️ مدیریت اطلاعات:** افزودن، ویرایش، حذف، جست‌وجو، دسته‌بندی، برچسب‌گذاری و علاقه‌مندی‌ها.
- **🔑 تولیدکننده رمز عبور:** ساخت رمزهای عبور قوی و قابل تنظیم.
- **🧪 بررسی کیفیت رمزها:** ارزیابی آفلاین رمزهای عبور با استفاده از قواعد و معیارهای محلی.
- **📦 پشتیبان‌گیری رمزنگاری‌شده:** ایجاد، اعتبارسنجی و بازیابی نسخه‌های پشتیبان.
- **✈️ پشتیبان‌گیری تلگرامی:** ارسال دستی فایل رمزنگاری‌شده گاوصندوق پس از تأیید کاربر.
- **⏱️ قفل خودکار:** قفل‌شدن گاوصندوق پس از مدتی عدم فعالیت.
- **📋 محافظت از کلیپ‌بورد:** پاک‌کردن خودکار رمزهای کپی‌شده.
- **⌨️ میانبرهای صفحه‌کلید:** دسترسی سریع‌تر به امکانات پرکاربرد.

## 📥 نصب و راه‌اندازی

### ویندوز

فایل نصب ویندوز با نام `espass-Setup.exe` را از بخش [انتشارهای گیت‌هاب](https://github.com/amires996) دریافت کنید؛ مشروط بر اینکه نسخه‌ای در آنجا منتشر شده باشد.

۱. فایل نصب را دانلود کنید.

۲. فایل Setup را اجرا کنید.

۳. مراحل نصب را دنبال کنید.

۴. برنامه را اجرا کرده و یک گاوصندوق جدید بسازید یا گاوصندوق قبلی خود را باز کنید.

> **نکته:** پس از انتشار اولین نسخه، لینک بالا را با آدرس دقیق بخش Releases مخزن جایگزین کنید.

### اجرا از سورس کد

**پیش‌نیاز:** Python نسخه 3.12 یا جدیدتر.

#### ویندوز (PowerShell)

```powershell
git clone <YOUR_REPOSITORY_URL>
cd espass

python -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1

python -m pip install -e ".[dev]"
python -m pyvault
```

#### لینوکس

```bash
git clone <YOUR_REPOSITORY_URL>
cd espass

python3 -m venv .venv
source .venv/bin/activate

python -m pip install -e '.[dev]'
python -m pyvault
```

## 🧪 آزمایش و بررسی کد

اجرای تست‌ها:

```bash
pytest
```

بررسی کیفیت کد:

```bash
ruff check .
```

## 🏗️ ساخت نسخه قابل نصب ویندوز

محیط مجازی پایتون را فعال کنید و دستور ساخت PyInstaller را از ریشه پروژه اجرا کنید:

```powershell
python -m pip install -e ".[dev]"

python -m PyInstaller --noconfirm --clean --windowed `
  --name espass `
  --onedir `
  --paths src `
  --icon assets/icons/espass.ico `
  --add-data "assets/icons/espass.ico;assets/icons" `
  --collect-all PySide6 `
  --collect-all cryptography `
  --collect-all argon2 `
  src/pyvault/__main__.py
```

فایل اجرایی ساخته‌شده را از مسیر زیر اجرا و آزمایش کنید:

```text
dist\espass\espass.exe
```

برای ساخت فایل نصب، فایل زیر را با نرم‌افزار Inno Setup باز کنید:

```text
packaging/installer/espass.iss
```

سپس گزینه **Build → Compile** را انتخاب کنید.

فایل نصب نهایی باید در مسیر زیر ایجاد شود:

```text
installer\espass-Setup.exe
```

## ☁️ پشتیبان‌گیری از طریق تلگرام

ESPass از پشتیبان‌گیری اختیاری از طریق تلگرام پشتیبانی می‌کند.

۱. با استفاده از [@BotFather](https://t.me/BotFather) یک ربات بسازید.

۲. از حسابی که قرار است نسخه پشتیبان را دریافت کند، گفت‌وگو با ربات را آغاز کنید.

۳. توکن ربات و مقصد ارسال را در برنامه تنظیم کنید.

۴. پیش از ارسال نسخه پشتیبان دستی، درخواست را تأیید کنید.

ربات تلگرام نمی‌تواند صرفاً با داشتن نام کاربری یک کاربر خصوصی، بدون آغاز گفت‌وگو از سوی او، مکالمه خصوصی جدیدی شروع کند.

فایل ارسالی شامل گاوصندوق رمزنگاری‌شده است؛ نه خروجی متنی و آشکار رمزهای عبور. برای بازکردن نسخه پشتیبان همچنان به رمز اصلی نیاز دارید.

پشتیبان‌گیری خودکار هنگام بسته‌شدن برنامه اختیاری است و به‌صورت پیش‌فرض غیرفعال است. در صورت فعال‌سازی، توکن ربات از طریق مدیر اعتبارنامه سیستم‌عامل نگهداری می‌شود.

**هرگز توکن ربات تلگرام یا اطلاعات محرمانه خود را در مخزن گیت‌هاب منتشر نکنید.**

## 📂 محل ذخیره اطلاعات

تنظیمات و گاوصندوق پیش‌فرض برنامه در مسیر اختصاصی داده‌های کاربر ذخیره می‌شوند.

| سیستم‌عامل | مسیر پیش‌فرض |
|---|---|
| ویندوز | `%LOCALAPPDATA%\espass` |
| macOS | `~/Library/Application Support/espass` |
| لینوکس | `$XDG_DATA_HOME/espass` |

اگر متغیر `XDG_DATA_HOME` در لینوکس تنظیم نشده باشد، معمولاً مسیر `~/.local/share` برای داده‌های برنامه استفاده می‌شود.

گاوصندوق‌های قدیمی موجود در پوشه PyVault نیز از طریق صفحه خوشامدگویی قابل شناسایی هستند. همچنین می‌توانید فایل `.pyvault` را از هر مسیر دیگری انتخاب کنید.

## 🔐 مدل امنیتی

ESPass از چند لایه امنیتی استفاده می‌کند:

- Argon2id برای مشتق‌سازی کلید از رمز اصلی.
- کلید رمزنگاری داده با مقدار تصادفی.
- AES-256-GCM برای رمزنگاری احراز هویت‌شده.
- رمزنگاری اطلاعات ورود شامل عنوان، نام کاربری، نشانی اینترنتی، یادداشت، دسته‌بندی، برچسب‌ها و رمز عبور.
- عدم ذخیره رمز اصلی به‌صورت متن آشکار.
- نسخه‌های پشتیبان رمزنگاری‌شده که برای بازیابی به رمز اصلی نیاز دارند.

### محدودیت‌های امنیتی

- پروژه هنوز ممیزی امنیتی مستقل نشده است.
- پایتون تضمین نمی‌کند که تمام نسخه‌های اطلاعات محرمانه از حافظه پاک شوند.
- بدافزار، کی‌لاگر، سیستم‌عامل آلوده، اسکرین‌شات یا نشست بازشده می‌تواند اطلاعات را در معرض خطر قرار دهد.
- بررسی کیفیت رمز عبور بر پایه معیارهای محلی است و پایگاه داده نشت اطلاعات را بررسی نمی‌کند.
- پشتیبان‌گیری مبتنی بر فایل است و بازیابی، دو گاوصندوق را با یکدیگر ادغام نمی‌کند.

## 🌐 زبان‌ها

ESPass برای ارائه رابط کاربری فارسی و انگلیسی در نظر گرفته شده است. رابط فارسی باید از چیدمان راست‌چین (RTL) و رابط انگلیسی از چیدمان چپ‌چین (LTR) استفاده کند.

مشارکت در ترجمه‌ها، بهبود دسترس‌پذیری و توسعه رابط کاربری مورد استقبال است.
